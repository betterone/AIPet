# Momo — a little life, unfolding

一只猫，四个相连的室内空间与一个可以走出去的后院。Unity 6.3 LTS / iOS 优先的虚拟宠物原型。

当前范围是可执行原型工程，正式发布仍受真机、视觉体验和长期用户验证门槛约束。项目不使用 LLM、账号服务、网络请求、分析 SDK 或付费资产。开发工具的 Unity 登录与许可证和游戏玩家无关。

网页原型可导出为 Unity WebGL 静态文件，适合部署到 EdgeOne Pages；构建、输入映射、存档边界和上线检查见 [WEBGL-EDGEONE.md](docs/WEBGL-EDGEONE.md)。

## 逗猫连扑与成长家园（2026-11-02）

- 「互动 → 逗猫连扑」开始单指短局：拖羽毛、等猫蓄势、收圈松手。60 秒或三次失误结束，支持近远落点、完美时机、连击阶段和一键重开；短局不消耗养猫体力。

## 后院洗澡（2026-10-29）

- 后院有可步入的浴盆，脚踩防滑盆底，水升到躯干中部，触碰产生波纹和小水滴；泡沫为有体积、半透明的球形泡泡，搓洗聚团、冲洗散落。走近点击，邀请当前猫自己过来，亲手完成打湿、搓泡泡、冲净和擦干；猫会观察、避水、暂停或拒绝。
- 盆沿托盘提供直立泵瓶、花洒挂座和毛巾；换工具自动拿取、按泵取液与收放。花洒使用有重力和碰撞的水束，海绵会压缩，毛巾会弯曲。
- 每只猫在前台后院活动时独立沾灰，完整洗澡恢复干净；离线不增加脏污，也没有不洗澡的健康惩罚。
- 操作、规则、检查入口与验证边界见 [BATHING.md](docs/BATHING.md)。

## 本轮新增（2026-10-22）

- 保留原生活区和玩耍区，新增小厨房、休息房与封闭后院。地面总面积从约 180 扩展到 468 世界单位平方；实际门洞、家具、花坛和树木共同构成绕行路线。
- 猫、玩家、滚球和触摸地面使用一致的世界范围；猫能主动探索新区域，找猫提示能区分四房与后院。
- 小厨房与后院各有一袋猫粮。走到袋子约 2.2 米内点击，右手伸出抓粮、翻掌；可以拿粮走动和拖动右手调整位置。饿且在附近的猫会先观察、靠近、闻手，再从掌心吃粮。
- 喂食时移动或拉远手，猫会暂停，停稳后再闻一闻、继续吃。点击猫头或轻缓滑动会伸出左手；有效抚摸增加亲密，亲近的猫吃好后会蹭手。吃饱、睡着或需要空间时可以拒绝。
- 左上角的饱腹与亲密图标叠加百分比并按进度填色；实际获得收益时有短暂缩放、光晕与浮动增量。喂食提示放到上方，避免盖住猫和手。

- 操作界面重排为浮动猫咪卡、圆形移动盘、「回忆／一起玩／找猫」主入口；设置、互动、视角和状态统一使用圆角底部面板。三种竖屏尺寸、探索与选猫流程回归通过。build 9 已覆盖更新到原 iPhone Momo 并成功启动，两份原存档安装前后逐字节一致；实际手机触控手感仍待体验。画面和证据见 [HUD-REDESIGN.md](docs/HUD-REDESIGN.md)。

## 当前实现

- 原创程序化房间与九种风格化猫；新增用户提供的混元灰虎斑外观，已减面、绑定骨骼并接入八段基础动作。房间默认使用导入猫，Settings 可切回原品种。导入猫尚无眨眼与嘴部动画，交付文件和边界见 [IMPORTED-CAT.md](docs/IMPORTED-CAT.md)。
- 需求驱动的自主行为：吃、喝、睡、玩、探索、望窗、梳理、休息；可解释评分、冷却与寻路。
- 点击猫、地面呼唤、拖动红球；对过密抚摸表现出需要空间。
- WINDOW 06：启动后穿过外墙窗口进入扩大后的房间中心，支持 360° 环视；默认用提速后的单指水平滑动，双指捏合调整远近。点击 Motion: off 后，手机转身与视线同向，上下倾斜控制垂直视线。实现与 AR 后续边界见 [WINDOW-VIEW.md](docs/WINDOW-VIEW.md)。
- 实际 Rigidbody 球、地面碰撞与移动结果回写。离线使用语义结果，不宣称离线精确物理重演。
- 命名、三种基础性格和三种毛色；有界关系值、玩球偏好与时段习惯，并以玩具篮、窗边垫和床毯呈现逐步熟悉的房间。
- 本地双检查点、SHA-256 完整性校验、原子提交、损坏回退；全部损坏时保留原档并停止覆盖。
- 离线补算、时钟回拨防重复、30 天上限、128 条事件缓存；Journal 会把关系阶段、性格倾向、玩球时段与真实事件一起呈现。
- 轻量设置、可关闭触摸音效、设备本地截图、F1 开发者诊断。
- 房间底部「一起玩」可直接试摸猫、滚球和呼唤，并提示对应手势；单指上下左右环视，双指张开／合拢快速调整远近。九宫格猫咪采用安静的展示动作，选中后再进入较丰富的互动。

## 运行 Unity 工程

固定版本：`6000.3.23f1`，Apple Silicon；iOS Build Support 必须与编辑器同版本。

1. 在 Unity Hub/CLI 完成个人账号登录，并激活符合实际资格的许可证。
2. 用对应编辑器打开本目录，等待依赖导入和脚本编译。
3. 执行菜单 `Momo → Prepare Project`，打开 `Assets/Momo/Scenes/PetHome.unity`，点击 Play。
4. 输入名字、选择性格与毛色，点击 `Welcome home`。

构建命令：

```sh
./scripts/build.sh mac
./scripts/build.sh webgl
./scripts/build.sh ios
./scripts/build.sh ios-simulator
./scripts/build.sh ios-window
```

本轮窗户视角的独立真机工程：`Builds/iOS-Window/Unity-iPhone.xcodeproj`。优先使用它体验新版本，原 `Builds/iOS` 的既有 Xcode 配置保留。
`ios-window` 脚本会保留并核对这个工程已配置的本地签名选项；可继续使用原 Team 和 Bundle Identifier。

如编辑器安装在其他目录，设置 `MOMO_UNITY_EDITOR` 为 Unity 可执行文件的绝对路径。macOS 输出在 `Builds/macOS/Momo.app`；WebGL 输出在 `Builds/WebGL`，需要安装同版本 **WebGL Build Support**；实体 iOS 输出在 `Builds/iOS`，再由 Xcode 配置自己的 Team / Bundle ID 并部署。`ios-simulator` 会单独输出 `Builds/iOS-Simulator`，可直接选择 Xcode Simulator，不需要实体设备签名。模拟器适合检查布局、鼠标模拟触摸、存档与基础行为；不能替代实体机性能、实际触摸手感、通知或设备生命周期验证。模板 Bundle ID `com.momo.aipet.prototype` 必须在分发前替换成你控制的唯一标识。脚本不会自动创建账号、上传构建或发布。

## 交互

- Come closer：从窗外靠近窗口；Step back：退回窗外。
- 转动手机或单指上下左右拖动房间：查看不同角落。找猫转向猫当时的位置；回正恢复初始方向。
- 桌面／网页：`WASD` 或方向键走动，鼠标左键点按／拖动互动，鼠标右键或中键拖动看四周，滚轮缩放；`Esc` 打开或关闭菜单。
- 互动：右下按钮或「菜单 → 一起玩」打开互动卡；回忆、找猫、拍照从右上菜单进入。
- 走近后点击猫／猫头：伸出左手轻抚，睡着时保持睡眠；频繁点击会要求空间。
- 点击厨房／后院的猫粮袋：右手抓粮并翻掌；拖动右手调整位置，可拿粮行走，吃的时候停稳；点「收起猫粮」结束。
- 拖动球：放开后滚球并邀请玩耍。太累或睡觉时不会立即响应。
- 点击地面：清醒时走近。
- Journal：查看关系阶段、性格倾向、正在形成的偏好与近期真实事件。
- 菜单 → 设置：声音、视角和感应；「视角与移动」内可设置自动／常显、看向速度和回正。模拟器仅支持拖动。
- F1：仅开发者使用的状态与评分面板。
- Enter：在领养页确认；J：打开回忆；P：关闭面板并保存本地照片；Esc：打开或关闭设置。

## 时间和数据约定

原型世界速度为真实时间的 6 倍，前台与离线一致，世界从上午 9 点开始。不是天气或现实时间联网服务。超过 30 天真实离线只补算 30 天并记录说明，不逐帧重放物理。

单用户、单写入者存档位于 `Application.persistentDataPath/Momo`。两个文件交替提交；一次异常写入最多回退到前一个已提交检查点。正常每 15 秒与交互后保存，后台切换也保存；突然断电可能损失最近一次尚未提交的变化。退出回调不是唯一保存机制。

目前没有云同步、换机导入和重置入口。卸载可能丢失宠物；截图也只保存在应用可写目录，未接入 iOS Photos 分享。此版本不应按成熟产品对外发布。
