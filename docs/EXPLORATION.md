# 走近猫、双区域探索与日常躲猫猫

更新：2026-10-20。源码版本目标为 0.2.0 / iOS build 7。

## 当前交付边界

本轮源码、声音资源、macOS Player 与 iPhone Xcode 工程均已更新。Unity 6000.3.23f1 的许可证恢复后，macOS Development Player 的自动探索检查、iPhone Release 未签名编译及本地签名编译均通过；使用工程原有 Team 与 Bundle ID 的新版已安装到连接的实体 iPhone。

## 新体验

- 原 12×10 生活区右侧连接 6×10 蓝色玩耍区；门洞在 x=6、z=-1.5…1.5。原床、食盆、窗、箱子与宠物存档坐标保留。
- 左下游戏摇杆拖动中央爪印行走，松手停止；前后按当前朝向走，左右侧移。摇杆位移无级映射速度：中心附近可精细挪步，推到外环最快每秒 2.4 世界单位。
- 空白处单指看方向、双指缩放；一指按方向键加另一指环视时不作为双指缩放。以手指起点区分移动与世界手势，避免 EventSystem 更新次序造成误判。
- 「找猫」根据当前观察者位置转向猫，遮挡时提示其所在区域；不移动猫。「回正」只恢复方向；设置中的「回到入口」恢复观察者位置。
- 墙、家具使用共享的二维导航几何；猫可进入的矮隧道和床垫另设站立观察者避让；玩家采用小步扫描和沿墙滑动，不能穿过家具或走进猫的身体。球的活动边界同时扩大。

## 走近感应

- 首次主动开启时申请相机权限；使用 iOS 原生 ARKit 的世界追踪，仅读取当前位姿和追踪状态。无需 AR Foundation 包，不渲染真实相机背景，不保存或上传摄像头画面。
- 水平真实位移按 1:1 映射，忽略上下晃动。距启用点 0.5 米提示，0.75 米限制继续向外移动；回到范围内后恢复，屏幕移动不改变这个物理起点。
- 开启位置追踪时由 ARKit 同时提供 1:1 转头，停止叠加原陀螺仪的 2.2 倍观看输入。单指拖动、找猫与回正可调整观看基准。
- 相机拒绝、设备不支持、采样无效、追踪受限或超过 0.3 秒没有新帧时，不使用位移；方向键继续可用。重新取得有效追踪时以当前镜头对齐，第一帧不产生位移。
- 弹窗、Boutique、退到窗外和后台暂停追踪；关闭后恢复原来的转头感应偏好。开启状态只保留在本次运行，不自动在下次启动申请相机。
- 0.75 米范围是小范围输入限制，不是现实障碍探测或安全边界。

原生插件只向 C# 提供状态、位置、朝向和循环帧序号；帧序号避免把长时间开机后的低精度浮点时间误判为丢帧。iOS 构建加入 ARKit / AVFoundation 链接与相机用途说明，模拟器仍使用屏幕控制。

## 日常主动逗人

不增加小游戏入口和计分。前台子状态依次为 Quiet、Invite、GoingToHide、Hidden、Peeking、Returning、Found。

- 精力至少 40、饥渴低于 80，不在睡觉、吃喝或要求空间时，允许发起邀请；首次静待约 30 秒后遇到合适的日常活动可发起。
- 邀请时看向主人、轻叫，约 1.8 秒后选择附近可达藏点。每次最多换两个位置，靠近后可绕开一次，随后停下来等。
- 藏起约 6 秒未被找到，叫一声并走到探头点；约 12 秒走到可见的等待点，再等约 10 秒无人回应就结束。路程异常超过 16 秒也会主动出现。
- 距离小于约 1.8 米、视线未受家具遮挡且猫在画面内，持续观察 1 秒视为找到；直接抚摸也可以找到。
- 被找到后轻叫、靠近、呼噜，约 4 秒恢复日常。单次“找到”只增加一次亲密反馈；结束冷却至少两分钟，性格安静的猫等待更久。
- 玩具和玩家明确互动优先。取消时保留猫独立的睡觉、进食和要求空间状态，不把它们覆盖成待机。
- 猫的位置和路线仍只有 Simulation 一个驱动者，表现层沿路线插值、脚步按实际位移推进。社交子状态不参与离线补算，也不增加 Activity 枚举或更改旧存档 schema。

## 声音

4 类声音事件：邀请、探头、被找到、呼噜。原有 8 段单声道 22050 Hz WAV：每类 2 段，来自两份 CC0 1.0 实录。

2026-10-22 新增用户提供的 5 个 MP3，共 13 段资源。按用户文件顺序绑定前五只猫：Mikan → `u_r9sp2mg8xc-meow-433426.mp3`；Earl → `yodguard-cute-soft-cat-meow-4-535483.mp3`；Chai → `sound_garage-cat-meow-12-fx-306191.mp3`；Oreo → `lazychillzone-cat-meow-loud-225307.mp3`；Yuki → `sound_garage-cat-meow-1-fx-306178.mp3`。这五只猫的邀请、探头和被找到事件统一使用各自的常规叫声，保留原呼噜；其余四只沿用原叫声。文件原样复制，来源及许可状态单独记录，不将新增文件标为 CC0。

启动按存档品种恢复声音，领养／预览切猫同步切换并停止前一只猫的声音。沿用音效开关、距离衰减和遮挡低通；冷却至少覆盖整段音频，避免长叫声叠加。

本轮已验证：40 项核心测试、桌面／iOS C# 分支与原生编译、13 段音频解码、Unity macOS 构建及播放器回归。播放器逐只验证前五只猫的领养绑定、三种常规叫声事件、静音、冷却、避免重叠，另检查呼噜保留、其他猫回退与启动选择。记录见 `artifacts/exploration/cat-voices.txt` 与 `artifacts/cat-voices-runtime.log`。本轮未构建或安装 iPhone 更新，手机扬声器听感待实际体验。

来源、授权、裁切位置及处理方式在 `Assets/Momo/Resources/CatAudio/SOURCES.txt`，设置中也可查看署名。运行时绑定猫的位置，距离衰减、遮挡低通、交替片段和播放冷却；沿用音效开关。没有把合成提示音改调后当猫叫，也没有声音生成服务。

试听：`artifacts/exploration/cat-voice-preview.wav`。萌感与手机扬声器上的听感仍需使用者实际试听。

## 真机验收清单

1. 解锁手机并打开已安装的 Momo；首次点「走近感应」时允许相机权限。
2. 验证前后左右位移方向、转头 1:1、0.5／0.75 米边界、追踪恢复、双手移动加环视、缩放不误触、前后台与 Boutique；连续体验 15 分钟检查流畅度和发热。
3. 在手机扬声器上分别听邀请、探头、被找到和呼噜，判断音量、嗲感、距离衰减与遮挡听感。
4. 孩子试玩：能发现方向键，约一分钟内找到并靠近猫，至少完成两次自然寻找。分别记录是否听懂声音线索、是否追得上、找到后是否感觉猫在回应。
