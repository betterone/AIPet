# 家园行为与后院寻趣优化（2026-11-09）

本轮目标是让猫分布到整个家园、主动回应玩家，并让探索形成一轮可以完成的小活动。

## 1. 分散活动，真正去后院

原行为反复把全部猫导向床、窗、球等少数固定位置；身体避让只能避免重叠，不能保证活动分布。现在睡觉、观察按猫分配不同位置，继续使用原有目标预留与身体避让。

新增仅前台运行的错峰巡游。第一轮机会按猫 ID 在约 13–33 现实秒出现，之后约 43–56 秒获得下一次机会；忙碌时等待，不打断睡觉、吃喝、玩家照料或猫间互动。巡游在房间与后院之间轮换，并预留不同目标。时间为正常六倍模拟速度下的机会时间，实际行动受猫当前状态和寻路影响。

## 2. 主动靠近和短距离跟随

当前选中的猫会主动获得亲近机会：首次约 3 秒，之后约 15–30 秒，保留性格差异。呼唤由直线可见且七米内改为三十米内可寻路，能够绕家具和房间隔墙走来。回应意愿门槛由 0.46 调整为 0.38。

回应时看向玩家；停在约 1.8 米外；招呼期间玩家走远超过三米且在十二米内，会重新规划跟随。只有当前猫主动跟随，避免所有猫再次围住玩家。睡觉、吃喝、低体力、急需吃喝、躲避、照料中的猫不会被强行召回。招呼结束后仍可恢复自主活动。

## 3. 后院寻趣

入口：**一起玩 → 后院寻趣**。

猫咪带路去三个后院角落，地面金色标记指示当前目标，屏幕保留轮次提示和走动控制。玩家走到目标三米内，猫到目标 0.4 米内，共同停留两现实秒后进入下一站。完成后缓解 18 点无聊，并保存一条共同探索记忆；没有重复货币和亲密度奖励。

切换猫咪、进入商店、其他主动照料／逗玩、切后台、紧急需求或超时会结束本轮；重新开始可再走一轮。进行中的轮次是本次访问的临时状态，完成记忆沿用现有存档，不改变 schema。
