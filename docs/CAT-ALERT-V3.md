# 猫的灵敏与警戒动作试片 V3

2026-10-10。用户明确拒绝 V2：猫的步态不对，应该更灵敏、有警惕性。V2 未通过自然度验收。

## 复查依据

- 普通猫步行常用同侧接续的落脚顺序：右后、右前、左后、左前。速度改变时接触期也会变化，不能以固定摆腿替代。[完整猫步态研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4044364/)。原 `prepare_cat.py` 的 `(t + offset)` 组合是后左、前右、后右、前左，未呈现这类普通步行的接续。V3 使用新的落脚规划；原 FBX 与正式房间尚未替换。
- 前肢运动包含肩胛运动，单纯在躯干下摆动整条腿不足以呈现步行。[猫前肢运动研究](https://pubmed.ncbi.nlm.nih.gov/1164673/)。现有骨架没有独立肩胛骨；V3 的肩部平移只是近似，无法替代成熟骨架与手工动画。
- 注意时耳朵前向与受惊、防御时耳朵和身体姿势不同。警戒不能始终做成贴耳、缩成一团。[爱丁堡大学猫肢体语言资料](https://vet.ed.ac.uk/sites/default/files/2024-09/Feline%20body%20language.pdf)。这些来源支持动作方向；片段中的反应时间是动画调度参数，并非生物学测量值。

## 本次实现

- `CatAlertStudy` 是独立试片，默认在现有 `MomoCatStudy.app` 中启动。
- 先注意刺激，再短步靠近、停下扫视；第二次靠近可被声音情境打断，猫转身退开后继续观察。
- 身体起停用 0.20 秒速度过渡，转向和头部注意的响应较 V2 加快。谨慎程度控制轻微重心下降、抬头程度、耳位和尾位。
- `CatAlertMotion` 以世界空间支撑点求解四肢，使用同侧前后足接续，加入肩部和躯干变化。已开始的抬脚在停下后仍完成落地，静止转向时逐脚重新落地。
- 调试时逐帧审片发现抬脚末端 `sin(pi)` 的浮点结果可略小于零，对负数取分数次幂会产生无效数值，引发某些帧前腿弹起。已钳制曲线，完成落脚时直接使用接触点，并逐帧拒绝非有限的骨骼末端误差。不能只看每秒抽样的包围盒或数值误差峰值。
- 原地转向不能保留转身前的腾空脚落点。V3 由角速度推动换步，并在腾空期间更新落点；转身时间也必须允许脚步完成，避免身体已经转过去、脚还留在旧方向。
- 换步最多允许两只脚同时腾空，优先处理离身体中立位置最远的支撑脚，避免前脚反复抢占动作、后脚留在转身前的位置。每次重放恢复完整基准骨架，不能依赖 FBX 被省略的恒定动画通道恢复上次 IK。
- 鼠标点击仅改变注意目标。`R` / `F` 重放有打断的片段；`C` 重放平静靠近；空格从当前位置触发打断，不跳到预设路线点。
- 旧版仍可用 `--cat-behavior-v2` 启动。本次没有修改正式 `Simulation.Call`、存档或正式房间的行为规则。

## 运行与验证

构建入口：`Momo.Editor.CatBehaviorStudyBuilder.BuildMac`。

应用：`Builds/CatBehaviorStudy/MomoCatStudy.app`。

自动录制：应用二进制加 `--cat-behavior-review`，固定 30 fps 逐帧记录；`python3 scripts/render-cat-behavior-study.py v3` 编码录像。

录像：`artifacts/cat-behavior-study/v3/review.mp4`；同目录 `FRAMECOUNT.txt` 与 `timings.txt` 记录真实帧数、片段时长、落脚数量和骨骼末端对规划点的误差。误差只衡量求解结果，并不证明步态自然、地面无任何穿插或毛皮形变正确。

本轮 Unity 6000.3.23f1 macOS Development Player 构建成功，最终重放完成：平静靠近 6.23 秒，受打断后退开并回头观察 8.03 秒。录制 429 帧，按 30 fps 编码为 14.30 秒录像，两段均通过逐帧有限值与接触点可达检查；每半秒抽帧复审未再看到前腿瞬间弹起。用户自然度验收仍待实际观看。最后尝试打开运行窗口时，电脑处于锁屏状态，无法完成当前窗口的交互确认。

## 未完成的质量门槛

这是本地程序动作试片，尚未通过用户自然度验收。当前模型仍缺少成熟走/小跑/跑步/急转/扑跳/落地动作、独立肩胛控制、眼睑和口部形变。若用户仍觉得像模型在移动，应切换到经过原始动作视频审片的成熟猫动画资源，并匹配本项目外观；不要把继续加平滑或随机摆动当作完成质量门槛。

另存了可公开下载的 CC0 候选：Quaternius 的 2017 年 Animal Pack Vol.2 包含 Cat.fbx 与 Cat.blend，并非之前查阅的 Ultimate Animated Animal Pack。原文件位于 `artifacts/animation-candidates/quaternius-cat/`，来源见同目录 SOURCE.md。FBX 二进制中的动画栈标签为 Idle 和 Walking；尚未在 Unity 中审片，不能承诺跑、跳或自然度，也没有替换 V3 的灰虎斑。
