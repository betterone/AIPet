# 四房后院与掌心喂食

更新：2026-10-22，0.2.0 / iOS build 10。

## 本轮交付

生活区与玩耍区保留原物品、床、食盆、窗和宠物坐标。北侧增加小厨房、休息房，再由两个敞开的门通往围合后院；厨房和休息房之间也有门，形成可以绕行的环路。地面面积从 180 扩到约 468 世界单位平方。院子包含双小径、花坛、果树和围栏。

猫、观察者和球共用扩大后的导航范围。家具、墙与花坛共同阻挡通路，站立观察者继续绕开猫可进入的床和矮隧道。旧版外围草地只是装饰，本轮后院具备真实地面、通路和导航。新增地面全部明确标记为可互动地面，修复只识别原 `Floor` 名字的问题。自主探索、躲藏点、找猫区域提示、滚球边界、路线长度和存档校验同时扩展。

## 喂食与双手

1. 小厨房和后院各有一只带爪印的猫粮袋。走到约 2.2 米内，点击袋子。
2. 右手从屏幕伸出、抓起一小把粮，再翻掌。拖动右手调整递手位置，可以拿着粮行走。
3. 饥饿值至少 25、清醒且不在吃喝或要求空间的猫，在约 4.5 米内、通路无遮挡时，先注意、观察，再自主走近并嗅闻。性格影响观察时间。
4. 手停稳、猫已走到递手位置并实际接近掌心后，才会吃粮。每把最多四口，每口最多降低 5 点饥饿，饥饿最低到 8 即停止。
5. 用户移动、拉远手、遮挡或嘴没有接近时，不扣粮、不计算进食收益。猫停下观察，手稳定后再闻一闻并继续。狭窄角落无法容纳掌心和猫的站位时，提示换到空地。
6. 走近点击猫头或轻缓滑动时，左手伸出轻抚，右手仍托粮。沿用原抚摸冷却与需要空间的规则，有效抚摸增加 1.5 亲密；喂食不被普通抚摸取消。
7. 一次喂食的首口最多增加 1 点亲密，至少间隔 360 模拟秒（正常约 60 真实秒）才可再次获得这份奖励；该冷却随存档保留。亲密至少 25 时，吃好后有轻微蹭手动作与呼噜。
8. 点「收起猫粮」、打开面板、切换选猫或逗猫棒、退到窗外及进入后台会结束或收回这次喂食。无人回应约 90 秒自动收手。睡着、吃饱或需要空间的猫可以拒绝。

饥饿、进食与奖励由同一份 Core 规则提交；猫的位置仍只由 Simulation 驱动。双手和猫头接触使用真实场景坐标，左手在猫动画与接触修正之后更新。没有保存未完成的手部动作，重开或离线不会继续吃手中的粮。基础食盆、饮水和离线照料继续工作，粮袋没有库存收费机制。

## 图标与画面

左上方常驻两个小图标：饱腹和亲密。图标按进度填色、叠加百分比，饱腹取 `100 - hunger`；低饱腹用暖黄／红，正常用绿，亲密用深浅粉色。有效收益触发短暂缩放、光晕、平滑进度和浮动增量；达到上限或被拒绝时不显示虚假的收益。

递手时自动把视线轻轻向下调整，保留水平朝向；手仍可拖动。递手横向范围按实际视宽限制。喂食提示移到画面上方，「收起猫粮」在右上方，避免盖住猫头、掌心和下方移动盘。

## 复查方式与待体验项

```sh
./scripts/test-core.sh
./scripts/build.sh mac
Builds/macOS/Momo.app/Contents/MacOS/Momo --garden-feeding-review -screen-width 390 -screen-height 844 -logFile "$PWD/artifacts/garden-feeding-review.log"
./scripts/build.sh ios-window
```

`--garden-feeding-review` 使用独立临时存档，绝不读取或覆盖真实宠物存档。检查结束会退出，PASS 标记只在全部检查通过后写出。

手机上仍需亲手体验：穿门与绕家具、走近粮袋的发现性、双手比例和触摸手感、停稳／拖动阈值、猫的自然度、陀螺仪和走近感应，以及持续运行的帧率和发热。本轮没有上传或提交审核。
