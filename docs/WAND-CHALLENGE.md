# 逗猫连扑与成长家园

2026-11-02，iOS 优先的本地玩法增量。第一人称陪猫，单指拖羽毛、收进圈、在光圈重合时松手。家园仍可自由喂食、洗澡、滚球、呼唤和逗猫。

## 进入与玩法

- 「互动 → 逗猫连扑」提供今日路线、自由练习、过去七天、自由逗猫。玩耍区门边的羽毛架可直接开始平地练习；解锁后的设施可点选开始对应练习。
- 60 个真实秒或 3 次失误结束。先拖动至少 0.65 米并持续至少 0.22 秒，猫进入可读的蓄势姿态；大圈 10 分，小圈 20 分。在收圈进度 45%–95% 之间松手算成功，65%–85% 为完美，获得 1.5 倍基础分。原地持有、轻点、单次瞬移、UI 点击不提供得分。
- 连续 3／6／10 次进入追起来、连着扑、默契时刻。阶段增加追逐速度、折返与两段扑抓节奏，阶段得分系数为 1.1／1.25／1.5；失误断连，已得分数和最长连击保留。
- 纸箱路线按猫身体范围绕行；隧道路线经过开口。近远落点与节奏由种子确定，判定不使用随机成功率。
- 结算展示分数、该猫在同场地／规则版本／种子下的最佳纪录、最近的一次失误建议和一个成长目标。一键原路线重开，另可回家或尝试已解锁设施。

## 成长与每日路线

- 每局至少 3 次成功为达标。家庭累计 2／8／20 个达标局解锁扑抓垫、矮纸箱和纸箱隧道；各猫累计 10／40／100 次扑抓掌握接羽毛、折返扑和绕障接扑。
- 本领和设施均保存在独立长期状态。家中设施是可点击的实体；条件合适的清醒猫会自己走近设施，展示蓄势、扑抓和学会的折返动作。不会为了展示唤醒睡猫。
- 配置位于 `Assets/Momo/Resources/PlayTuning.json`。调整成长阈值会保留已经取得的本领与设施。改变判定或得分规则时应递增 `rulesVersion`，避免把新旧规则的纪录混为一谈。
- 推荐使用设备本地现实日期，与六倍世界时间分开。首次发现当天组合后固定，升级设施不会改变当天路线；最近七天可反复玩，无限时专属奖励。自由练习始终可玩。

## 状态和生命周期

- `WandChallengeSession` 不依赖 Unity，持有局内计时、输入、目标、运动、判定和只读结算。`WandArena` 负责小场地的路径。
- 挑战使用独立场地、猫模型和相机；实际家庭生命模拟继续推进。挑战不写回家庭的猫位置、照料精力或社交状态，结束仅提交一次成长结果和一条实际游玩回忆。
- `PlayProgress` 保存每猫成长、设施、按猫／场地／规则／种子区分的纪录、每日组合与有界本地事件。事件仅含日期、事件种类、局号、猫 ID 和数值；不接分析 SDK、账号或网络。
- schema 3 家庭档显式读取 schema 2 家庭档与 schema 1 旧单猫档。迁移读档不覆盖原文件，首次写新档前将读到的 schema 2 原字节保存为带摘要的 `.bak` 文件。继续使用校验、双检查点和原子提交；全部损坏仍停止覆盖。
- 开局先保存递增局号；只有当前局可结算一次。后台中止未完成局，丢弃临时动作，不发放该局奖励；重启会清理未完成局号。存档失败遵循原应用的提示与重试机制。
- 「设置 → 试玩记录」导出本机 `Momo-play-log.json`。导出包含成长汇总和有界事件，最近 512 条事件／256 组纪录；不作为无限期用户分析仓库。

## 验证入口

`./scripts/check-play.sh`：核心测试、iOS 条件编译、macOS Player 构建、320×700／390×844／768×1024 的显式渲染目标检查，并回归原有 HUD、五猫、喂食和洗澡。

开发 Player 参数：`--wand-challenge-review --play-review-size=390x844`。使用独立临时存档，输出 `artifacts/wand-challenge/<尺寸>/`。覆盖生产拖动／松手入口、近远目标、10 连击、结算与重开、真实后台入口、不消耗家庭照料精力、设施和全部可领养外观的蒙皮有限性及 Unity 存档往返。

动作是当前骨架上的手工程序化地面短追／蓄势／扑抓／回稳，使用关节和接地求解；没有把加速播放 Walk 当作新增跑步动作。蒙皮有限、规则通过不能替代对自然度和乐趣的人眼验收。

## 尚需真实玩家完成的验收

采用 `docs/PLAYTEST.md`，由 10 名普通休闲玩家进行无口头教学试玩与随后七天自由试玩。自动检查只能说明实现和布局可运行，不能证明一分钟理解、主动三局或跨天回访目标已经达成。iPhone 真实触控、动画自然度和持续发热／帧率也须独立记录。
