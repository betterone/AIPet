# Boutique：先认识，再带回家

2026-09-28。基于手机反馈持续调整的运行版本；角色继续使用现有程序化猫模型。

## 体验与修复

- 打开 Boutique 默认回到九宫格。打开按钮的松手不会穿透并误选猫咪；从 UI 开始的手势也不会触发舞台。
- 九宫格里的猫保持安静姿态，只保留细微的眨眼和耳朵动作；选中后才播放完整待机与互动动作。九宫格镜头按完整展架和可用视口计算距离，名字牌随实际 3D 投影定位。
- 单猫页使用相同角色和坐垫，隐藏周边展架。镜头按角色渲染包围盒、动画余量及视口比例取景，保留耳朵、尾巴与爪子。
- Boutique 使用独立灯光层，避免房间的方向光叠加造成白猫过曝；背景相机清理整个画面，避免视口切换后残留上一帧。
- 专用自适应 Canvas 和安全区：姓名、毛色、初识印象在上方；外观介绍、短反馈、三个互动、命名和主按钮在下方。短屏和平板保留足够的猫咪展示高度。
- 支持上一只／下一只，浏览时分别暂存每只猫的名字。既有宠物再次选择时，先说明会更改名字、外观和初始性格、保留相处记录，再由第二次点击提交。
- “看这里”实际触发朝向与视线，不再触发哈欠。移除没有对应实现的呼噜音效描述。性格百分比改为初识印象，不把模板参数当成相处结果。
- 打开单猫页后，点右上方「档案」可查看该猫的名称、品种、外观特征、性格概括，以及玩心、好奇心、亲近人和独立性四项初始倾向。「继续认识它」返回原猫页面；档案不编造生日或经历。

## 本地验证

`BoutiqueReview` 仅在 Development Player 显式传入 `--boutique-review` 时运行，存档使用独立临时目录，不修改正常玩家存档。正常游戏没有自动切换、截图或退出行为。

运行方式：

```sh
./scripts/build.sh mac
Builds/macOS/Momo.app/Contents/MacOS/Momo --boutique-review -logFile "$PWD/artifacts/boutique-review.log"
./scripts/build.sh ios-window
```

检查包括九宫格实际射线选择、打开时的松手隔离、UI 手势隔离、九只猫的渲染包围盒、抚摸和舒展后的画面边界、逐只档案打开与返回、文字高度、UI 屏幕边界、展示区至少占屏幕高度的 30%、返回九宫格、领养保存、房间相机恢复及再次打开。批处理模式不会生成截图，也不会实际切换窗口尺寸；多尺寸画面验证以窗口模式日志和截图为准。

最终运行尺寸为 390×844、375×667、430×932、768×1024（前轮 macOS 曾将第二种对齐到 376×668，以日志为准）。截图属于桌面 Player 多比例验证，不是 iPhone 或 iPad 真机截图。
