# 探索界面精简与自动隐藏

更新：2026-10-29。目标是让猫和房间成为画面主体，同时保留明确、可找回的操作入口。

按用户反馈，将左下方向盘恢复为固定常驻底座；只有次要入口自动隐藏。下文为该修正版规则。

后续已覆盖更新到实体 iPhone 的 0.3.0（16），存档保留与启动状态见 [IPHONE-BUILD16.md](IPHONE-BUILD16.md)。

## 画面层级

- **探索**：左上小型猫咪入口、右上 `⋯` 菜单、右下「互动」。撤掉底部整条工具栏和常驻拍照／回正按钮；饱腹、亲密不再常驻。
- **移动**：左下约 176×176 逻辑点为拇指区，固定显示 96 点方向盘。拖动爪印控制方向和速度；松手立即停止并回中，约 0.35 秒恢复淡色底座。控件组静置透明度为 0.65，按住为 1，静置不消失。
- **菜单**：回忆、找猫、拍照、一起玩和设置集中到 `⋯`；点猫咪入口仍可选猫或看完整状态。回正、返回入口与感应开关留在视角设置。
- **提示位置修复（2026-10-29）**：提示卡始终位于完整方向盘触摸区上方，留 12 逻辑点间距；按实际控件顶边计算，适配安全区与缩放，不再盖住常驻方向盘。
- **提示**：移除常驻玩法说明卡，只保留首次引导、当前对象提示和短时反馈；自主行为和普通通知不会重置自动隐藏计时。
- **感应警告**：相机权限未获准、追踪暂不可用或走近感应达到位移提醒范围时保留必要提示，不因静置淡出；正常的感应开启说明不常驻。
- **照料**：喂食只保留收粮和必要状态反馈；洗澡卡从 174 点压到 108 点，换工具按钮仅在当前步骤完成时出现。退出始终可见，防止被自动隐藏困在操作中。

## 自动隐藏与唤回

1. 普通探索连续六个真实秒没有输入，猫咪入口与互动按钮在约 0.3 秒内淡出，保留右上淡色菜单和左下固定方向盘。
2. 静置后的首个场景轻点只唤回界面，不触发摸猫、切猫、抓粮或打开洗澡邀请。第二次轻点正常操作。
3. 拖动看四周不需要先点一次，同一手势立即转动视角；在左下方向盘拖动同样可以直接行走。
4. 移动、手指持续按住、打开菜单、喂食、洗澡、逗猫棒和进出房间时不隐藏必要操作。切后台清空移动，回来后重新显示辅助界面。
5. 隐藏的按钮同时停止拦截触摸；菜单和透明的移动激活区仍可用。移动触点与视角触点保持独立。

在「菜单 → 设置 → 视角与移动 → 界面显示」切换自动／常显。偏好只保存在本机 UI 设置，不修改猫咪档案、世界时间或养成状态。

常显会保留精简后的三个入口；方向盘在自动和常显模式下都会保留，不恢复旧版底部工具栏。

## 实现与检查

`HudVisibility` 只处理真实时间与显隐状态；`MomoHud` 负责界面分组和必要操作；`WalkPad` 保持触点占用、固定中心和松手停止；`MomoApp` 负责唤回手势与世界操作之间的防误触。

检查入口：`./scripts/check-quiet-hud.sh`。开发参数 `--quiet-hud-review` 使用独立临时家庭档，不改玩家的宠物存档，也不持久化测试中的自动／常显切换。截图输出在 `artifacts/quiet-hud/`，其中 `before-390.png` 是本轮改动前保留的桌面截图，其他为新构建实际渲染。

核心检查覆盖计时、持续输入、照料保护、常显与无效时间；Player 检查覆盖按钮数量、透明 UI 射线、首点不误操作、首次拖动即时响应、固定方向盘和视角同时操作、菜单功能、照料退出与不同屏幕比例。最终通过结果以 `PASS.txt` 和日志为准，真机触摸舒适度与自然度需要另行体验。
